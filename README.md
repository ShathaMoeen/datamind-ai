# DataMind AI

DataMind AI is an AI-powered data analysis platform that combines deterministic
Python analysis, LLMs, specialized AI agents, visualizations, and RAG.

## Project status

The project is under active development and is being built incrementally.

## Planned features

- CSV and Excel dataset analysis
- PDF document ingestion
- Specialized AI agents
- Controlled data-analysis tools
- Interactive visualizations
- Retrieval-Augmented Generation
- Evidence-grounded analytical reports
- FastAPI backend
- Automated tests

## Architecture

The system will separate:

- LLM reasoning from Python computation
- Agent decisions from controlled tool execution
- Calculated facts from AI-generated interpretations

Detailed architecture documentation will be added under `docs/`.
